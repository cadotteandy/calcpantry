Decimal vs binary units

There are two ways to count storage. The decimal (SI) system goes up in steps of 1,000, just like kilometers and kilograms. The binary system goes up in steps of 1,024 (2¹⁰), which is how computer memory is addressed. Since 1998 the binary units have their own names (kibibyte, mebibyte, gibibyte) but Windows still shows them with the decimal labels, which causes endless confusion.

The formula

bytes = amount × unit size
decimal: 1 KB = 1,000 B, 1 MB = 10⁶ B, 1 GB = 10⁹ B, 1 TB = 10¹² B
binary: 1 KiB = 1,024 B, 1 MiB = 1,024² B, 1 GiB = 1,024³ B, 1 TiB = 1,024⁴ B
bits = bytes × 8

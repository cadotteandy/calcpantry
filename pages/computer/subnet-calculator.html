How subnetting works

An IPv4 address is 32 bits, usually written as four numbers from 0 to 255. The prefix length splits those bits into two parts: the network portion (the first bits, shared by every device in the subnet) and the host portion (the rest, unique to each device). Masking the address with the subnet mask keeps only the network bits, which gives the network address.

The formula

subnet mask = prefix ones followed by (32 − prefix) zeros
network = IP AND mask
broadcast = network OR (NOT mask)
total addresses = 2^(32 − prefix), usable = total − 2

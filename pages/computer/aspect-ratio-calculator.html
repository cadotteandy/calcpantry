How aspect ratio works

Aspect ratio is the shape of a picture: its width compared to its height. Two images with the same ratio can be scaled up or down into each other without stretching. Resizing means keeping width ÷ height constant, so once you fix one side, the other follows.

The formula

ratio = (width ÷ gcd) : (height ÷ gcd)
new height = new width × original height ÷ original width
new width = new height × original width ÷ original height

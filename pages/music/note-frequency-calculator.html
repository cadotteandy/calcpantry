How note frequencies work

Modern Western music divides each octave into 12 equal semitones. An octave up doubles the frequency, so each semitone multiplies it by the twelfth root of 2, about 1.0595. Everything is anchored to one reference note, A above middle C (A4), which is 440 Hz in standard tuning. Change the reference and every other note moves with it.

MIDI numbers each key from 0 to 127, with middle C as 60 and A4 as 69. That makes the math simple: count semitones away from 69 and apply the formula.

The formula

MIDI number n = 12 × (octave + 1) + semitone (C = 0, C♯ = 1 … B = 11)
frequency f = A4 × 2^((n − 69) ÷ 12)
from a frequency: n = round(69 + 12 × log2(f ÷ A4))
cents off = 1,200 × log2(f ÷ f of nearest note)
wavelength = 343 m/s ÷ f

Tips

  • Tuning by ear? Within about 5 cents is usually close enough for a single note; chords and unisons reveal smaller errors as slow beating.
  • Mixing: knowing a bass note's frequency helps you place EQ cuts and set a kick drum's pitch to sit with the key.
  • Room acoustics: low notes have long wavelengths (A1 at 55 Hz is over 6 m), which is why small rooms struggle with bass.
  • Octave labels differ. If your DAW shows a note an octave off, check whether it calls middle C C3 instead of C4.

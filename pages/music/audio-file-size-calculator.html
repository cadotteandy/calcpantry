What sets an audio file's size

Uncompressed audio such as WAV and AIFF stores every sample. Its size depends only on how many samples there are per second (sample rate), how many bits each sample uses (bit depth), how many channels there are, and how long it runs. Compressed formats like MP3, AAC and Ogg Vorbis instead target a bitrate, so their size depends only on the bitrate and the length.

The formula

uncompressed bytes = sample rate × (bit depth ÷ 8) × channels × seconds
compressed bytes = kbps × 1,000 ÷ 8 × seconds
MB = bytes ÷ 1,000,000   ·   MiB = bytes ÷ 1,048,576
bitrate (kbps) = sample rate × bit depth × channels ÷ 1,000

Tips

  • Plan recording sessions by track count. 16 mono tracks at 48 kHz / 24-bit use about 138 MB per minute, or about 8.3 GB an hour.
  • Lossless compression such as FLAC or ALAC typically shrinks WAV files to roughly half to two thirds of their size with no loss in quality.
  • Higher sample rates double the storage for 96 kHz versus 48 kHz; use them when you need the extra headroom for processing, not by default.
  • Windows shows MiB as "MB". If a file looks smaller in Explorer than here, compare with the binary units line.
